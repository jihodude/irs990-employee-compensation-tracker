How It Works

1
Downloads the IRS filing index (~80 MB per year). In Most Recent mode it searches the newest index first, then falls back to earlier years for any org not yet found. Filings indexed in a given year typically cover fiscal year 1–2 years earlier.
2
Looks up each org by EIN to find which IRS batch file contains their 990.
3
Downloads only the specific XML from that batch — no full ZIP download.
4
Extracts Part VII compensation — names, titles, and dollar amounts.
5
Writes a clean CSV ready to open in Excel.
